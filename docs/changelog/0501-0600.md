## 507. The npm audit gate lets through a dev-only advisory with no fix

**Status: on main, not released yet.**

The Security Audit run on the 0.39.0-2 release commit failed on GHSA-fc5q-39xc-vjpf, a ReDoS in `picomatch` <= 4.0.7

critical advisory not in `scripts/npm-audit-allowlist.json`; an allowed one fails again once GitHub lists a patched
version or its review date (here 2027-01-31) passes, so it cannot stay hidden. Tests in `src/lib/npmAudit.test.ts`.

## 509. Moving a cancelled meeting to a day that already has it merges the text

**Status: on main, not released yet.**

Reported by Marien on 0.39.0-2 (2026-11-18): a recurring meeting cancelled today had text, he chose "Move to another
day" for tomorrow, and tomorrow's note, which already had that meeting, got a second section for it at the end.
`appendRemovedSectionTo` always appended. Now, when the target day has a section for the same meeting (matched by title
as the reconciler matches, so case and `[CANCELED]`-free titles; a `[CANCELED]` section is not a target), the moved
text goes at the end of that section, after a blank line when it already has text. With no such section it is
appended as before. Only the review's move changes; Flag and Discard are as they were. Tests in
`src/lib/calendarReconcile.test.ts`; spec §3.4 updated.
