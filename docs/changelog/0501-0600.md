## 501. Random typing against the real editor (T2)

**Status: on main, not released yet.**

Brief `docs/briefs/wave-4/T2-random-typing.md`, PR #255. The table tests check the cases someone thought of; §477 was
found only by a random test. `src/lib/editor/randomTyping.property.test.ts` feeds 300 random sequences of 1-25
actions (typing, Enter, Shift-Enter, Tab, Shift-Tab, Backspace, Delete, Mod-1..7, Mod-Shift-o, Home, End, arrows,
paste, random selections) to the real editing extensions, starting from 1-8 lines of list, action, topic, follow-up
and title lines. After every action: nothing throws, the selection stays in the document, no `\r`. After the
sequence: undoing everything gives back the start text exactly, and renumbering a second time changes nothing.

- No findings. Five runs of 3.7-4.2 s.
- The brief's negative check (an extra `Mod-1` before undoing) could not fail, since that keypress is undone too; the
  coder verified with an insert kept out of the history instead.

## 502. A ceiling on type escapes (R4)

**Status: on main, not released yet.**

Brief `docs/briefs/wave-4/R4-type-escape-ceiling.md`, PR #256. `scripts/type-escapes.mjs` (`npm run type-escapes`)
counts `any` type nodes (with the TypeScript parser) and `@ts-ignore` / `@ts-expect-error` / `@ts-nocheck` directives
in `src/` (`.ts`, and the `<script lang="ts">` blocks of `.svelte` files) and `tests/`. The count is kept in
`scripts/type-escapes.baseline.json`; `npm run verify` and CI's Frontend job fail when it rises, naming each file that
went up. `--update` lowers the ceiling and refuses to raise it: raising means editing the JSON by hand, so it shows in
a diff.

- Ceiling at the start: 164 (136 `any`, 28 directives; 14 outside test files). The hand count of 102 on 2026-11-15
  left out most test files.
- One rule line in `docs/briefs/RULES.md`; spec §8.

## 503. The numbered-list rules as tables that run (T1, step 1)

**Status: on main, not released yet.**

Brief `docs/briefs/wave-4/T1-spec-tables-lists.md`, PR #257. The numbered-list paragraph of spec §2.4 (about 6,000
characters) is now `docs/spec/lists.md`: 23 rules (L1-L23, in the old paragraph's order), each a short statement and a
Before / Keys / After table, 163 rows. `src/lib/editor/specTables.test.ts` reads every `docs/spec/*.md` and runs each
