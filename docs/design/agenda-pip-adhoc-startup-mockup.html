2. Ad-Hoc Calls Grammar & Syntax Support Supports ' and ’ with space

Area 2

Regex: /^\s*['’]/. Any Setext header starting with ASCII single quote (') or typographic quote (’), with or without spaces, is treated as an ad-hoc call.

Supported Syntax Variations:
'Quick Sync with Dave ===================== # Agreed to push deploy ' Call with Architect ===================== Reviewed schema migrations ’Ad-hoc Customer Check-in ========================= Customer requested export feature
Behavior During Calendar Sync:
  • Never matched to .agenda.json (excluded from agenda matching).
  • Never flagged as removed (no false-positive modal warnings).
  • Preserved in place: stays at its exact relative position between surrounding meetings.
  • Zero pip triggers: presence of ad-hoc calls does not cause the notification pip to light up.

3. Silent Auto-Sync on Blank Note Open Caret on Line 3

Area 3

Opening an empty note for today or a future date with calendar sync enabled automatically loads today's agenda meetings and focuses the cursor right under the first header.

Immediate Ready-to-Type Editor State:
1: 09:00 Daily Standup 2: =================== 3: 4: 5: 14:00 Architecture Review 6: =========================
No review modal prompt; user starts typing notes immediately. Clean tab state is maintained until typed.
