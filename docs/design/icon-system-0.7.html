chrononote

One icon set for the whole application, drawn from the app’s own vocabulary — the section rule, the dated page, the action box, the forward mark. It replaces the emoji currently used in the top bar and every modal header with a single monoline SVG set that follows the theme the way the editor glyphs do.

Three directions below — A Ruled, B Cell, C Marks — shown at the sizes the app renders. Set A is drawn in full; B and C are character studies of the same handful of functions so the direction reads without committing every glyph.

Today — v0.6.6

The top bar and modal headers are emoji. They don’t follow the light/dark or colour/grayscale setting — filter: grayscale(1) forces them flat, then color mode removes the filter, so the emoji render in Segoe UI Emoji’s own colours against the deliberate cyan/emerald/violet glyph palette. The tab strip, meanwhile, already uses a custom monoline SVG pair. Two systems, 40 px apart.

A

Ruled

Every mark built on the page + section‑rule metaphor: a 24×24 grid, ~1.75 stroke (≈1.5 optical at 16 px), round caps and joins, stroke: currentColor, no fill. This is the tab‑strip language promoted to the whole app, and it sits naturally against the --edge-soft hairlines from the 0.6 surface pass.

Themes for free. Icons inherit color — --text in the top bar, --tab-active-border on the active tab, --muted in a modal header. Chrome icons stay neutral in every colour mode; the semantic hue belongs to the glyphs, not the toolbar.

B

Cell

Built from monospace grid cells and a caret block — a direct read of the “tabular monospace grid” tenet. More geometric, more distinctive, unmistakably a text tool. The cost is legibility at 16 px: a cluster of cells can read as noise where a single contour wouldn’t, so several icons would need a dedicated small variant.

C

Marks

Each icon foregrounds the literal editor glyph it relates to: Actions is a stack of ☐; Section history is « over a run of dates; Search is a lens over a real ==== rule. The strongest one‑to‑one mapping and the most character — and the busiest at small sizes, where the glyph detail collapses.

Best use: not the toolbar, but the empty states of the three reading drawers — where there’s room, and the mark becomes a small demonstration of the vocabulary itself.

Shared chrome marks

The small repeated marks — today a mix of ‹ ›, ✕, ⌃ and a bordered ?. One chevron pair and one ×, shared by the find bar, the date‑picker month nav, and every close affordance. The warning mark (⚠ today) redrawn to the same grid for the Safety and Conflict modals.

The application icon rejoins the family

The current OS icon is the §96 “checkbox‑clock” — unrelated to anything drawn inside the app. In Set A it becomes the same dated page under its rule that the Open date note toolbar button uses, so the taskbar icon and the button read as one thing. The OS icon stays a single baked variant (regenerated with npx tauri icon); only an in‑app inline SVG can follow the runtime setting.

Neutral tile, accent mark. tile is --surface-chrome (#252526 dark / #f3f3f3 light) with an --edge-soft hairline; the mark is accent blue in colour mode, ink in grayscale — exactly how the glyphs behave.

Shipping it

where they live
One <Icon name="…" size={16} /> Svelte component over an inline path map in src/lib/icons/. No icon font, no dependency — the CSP forbids external assets and the app is offline‑first.
theming
Every path is stroke: currentColor. The button sets color; light/dark and colour/grayscale fall out of the existing tokens with no per‑icon rules.
modal headers
reuse the same path as the matching toolbar action, at 15 px in --muted — opening Actions shows the Actions icon in its header, not a second unrelated emoji.
new marks
Update available (down‑arrow into a tray, dot badge when active) and Calendar import (dated page + sync arc) are drawn into the set now, for the 0.7.x / 0.8.0 features.
tests
visual.spec.ts’s gallery picks them up automatically; one new assertion that no .icon-btn contains an emoji codepoint.

Recommendation

Ship Set A for the toolbar, modal headers and chrome marks, and redraw the OS icon as its “day” mark.

Hold Set C’s glyph‑forward treatment for the reading drawers’ empty states, where size isn’t a constraint and it doubles as a demo of the token vocabulary. Set B is the more radical option if ChronoNote wants a sharper, more proprietary silhouette — but it needs a full small‑size variant pass.
