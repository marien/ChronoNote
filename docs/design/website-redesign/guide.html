Start here

You need three things to get going. Everything else on this page is there when you want it.

  1. Give a meeting or topic a title and underline it with ===. That makes a section.
  2. Start a line with a mark: # for a to-do, => @name to hand something off, o for a topic to discuss.
  3. Press Ctrl+K for every other command. The palette shows each one's shortcut, so you learn them as you go.

It is all text. Type over a mark to change it, select and delete, paste from an email, undo. The glyphs follow.

The marks

      
Each mark is one to three characters, typed at the start of a line. On screen it becomes a glyph of exactly the same width, so nothing shifts while you type; in the file it stays what you typed.

      

      
Click a glyph to close an open action, or to reopen one that is done, deferred or won't-do. On a line with several actions (# call Sam => # book a room) a click changes exactly the glyph you clicked. From the keyboard, Ctrl+1 to Ctrl+4 set the action nearest the caret, or turn a plain line into one.

Getting text back

      

        
ChronoNote keeps earlier versions of each note: one every few minutes while you edit today, then one per day, for 30 days. Right-click a tab and choose Earlier versions… to compare any of them side by side with the current text and restore it. The current text is kept as a version first.

        
A note you delete with text in it goes to Recently deleted (in Settings) for 30 days. In the desktop app both are hidden folders inside your notes folder, so they travel with it; the web app keeps them in the browser's storage.

      

    


    

      
Export and print

      

        
Export a note or a date range as Markdown or standalone HTML from the More menu, the tab menu or the command palette. Actions become - [ ] checkboxes and section titles become ## headings. Copy a selection as Markdown from the editor's context menu, or print the note (Ctrl+P) with the glyphs styled for paper.

        
      

    


    

      
Bringing notes in

      

        
Settings → Notes & Sync → Data → Import notes from a file… brings in notes once they are in ChronoNote's format: one .txt file per day, with marks like # and =>. The migration guide on GitHub describes the format precisely enough to hand to a conversion script or an AI assistant.

        
In the web app you can also drop a backup or a day's .txt file onto the window. A note for a date that already exists is never overwritten: you see both versions and choose.

      

    


    

      
On your phone

      

        
The web app is the same editor, with a bar above the keyboard for the marks and actions. Long-press a glyph for that line's menu. Add it to your home screen and it opens full screen like an app, without a store.

        
Installing it

        
Open app.chrononote.mariendegelder.nl in your phone's browser. In Chrome on Android: menu (⋮) → Add to Home screen. In Safari on iOS: Share → Add to Home Screen.

When a note changed in two places

        
Changes from both sides are merged line by line. Only when both changed the same lines does ChronoNote hold the note back and show ⚠ 1 sync conflict; tap it to choose which version to keep, or keep both. Nothing is overwritten until you choose.
