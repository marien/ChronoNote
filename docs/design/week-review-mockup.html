Sections as in the note

Each meeting is its title with the note's double rule under it, instead of a grey uppercase bar. The rule is as wide as the title's own === line.

One editor line per item

Rows are 13 px Cascadia Code at line height 1.6, the editor's own rhythm (about 21 px), instead of 36 px boxes. Glyphs, tree lines, pills and the due flag are the editor's.

Selection

A light background with a thin accent edge on the left, instead of a solid blue bar, so a selected line still reads as text.

Earlier weeks, exactly

The link opens the Action Drawer on all files with before: (the Sunday before the shown week) and is:open filled in, so it lists exactly the actions the number counts.

Show done

Tick "Toon voltooid" in the mockup: done items appear in place, in their own colours, and a section's "alles voltooid" line gives way to them.
