The Root Cause
Current: 41% Canvas Area

The mark is only 424px wide inside a 1024px canvas with huge 300px outer margins. Plus, the 4 horizontal lines look like an anonymous code snippet or equalizer, not a calendar.

Proposed: 74% Optical Weight

Tightly bounded silhouette matching Windows 11 Fluent guidelines. Instantly recognized as an agenda tear-sheet with binder pins, scaled perfectly for 24px and 40px taskbars.
