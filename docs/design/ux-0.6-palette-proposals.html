Surface tiers (B & C)

Both proposals replace today's two surfaces with four, so depth is expressed by tone rather than by a border alone. Values shown for C; B uses the same roles on the current charcoal.

Tier 0 · Canvashsl(220 14% 10%)Editor background.
Tier 1 · Chromehsl(220 14% 13%)Top bar, status bar.
Tier 2 · Overlayhsl(220 14% 17%)Popovers, modals, drawers.
Tier 3 · Hoverhsl(220 14% 22%)Hovered rows, inputs, chips.

Action glyphs — shape & colour

The shapes get redrawn as checkbox-style marks inside the existing two-character cell (no gutter, column alignment preserved). Colour only applies in color mode; grayscale keeps distinguishing by weight and opacity.

TokenGrayscale (default)Colour mode (refreshed)Meaning
#  ☐ open ☐ open Unresolved. Blocks tab close, counts in "Open".
v  ☑ done ☑ done Resolved. Label text dims to ~55%.
>  » deferred » deferred Pushed to a later day. Counts in "Forwarded".
x  ☒ won't do ☒ won't do Closed without doing it. Strikethrough.

How to choose

All three ship the same 0.6 features. The choice is only about the surface they land on.

Pick A if
the look is fine and you'd rather I spend the whole budget on features.
Pick B if
you want the window to feel more deliberate and layered without relearning it. My recommendation.
Pick C if
0.6 is the moment to give ChronoNote its own visual identity and you're up for a tuning round.
