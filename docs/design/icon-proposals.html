chrononote

Three directions for the app icon. The current one is a stock clock — it says time and nothing about notes or actions. Each proposal below is drawn from the app’s own vocabulary and shown in both glyph color modes, at the sizes Windows actually renders.

Now shipping — v0.4.3

A

Checkbox clock

The open-action glyph ☐ is the app’s most-seen mark; two hands set inside it turn the box into a clock face. One shape holds both halves of the name — the action list and the passage of days. It stays a clean silhouette down to 16 px, where the list concept (B) turns to mush.

Follows the color setting. Tile stays neutral in every mode, exactly like the app’s chrome. Grayscale mode → the mark is ink. Color mode → the mark is accent blue (#007acc) — not a status hue, so it never reads as “done” or “overdue.”

B

The day’s list

A dated page under its === section rule, carrying the two states that drive the daily loop: one still-open action, one carried forward. It is the most literal picture of what ChronoNote is for — and the proposal where the two color modes read as genuinely different objects.

Follows the color setting — hardest of the three. Grayscale mode → both glyphs are ink, told apart by shape and weight (the app’s real grayscale philosophy). Color mode → open is red #ff6b6b, deferred is amber #e5a50a — the exact token palette. At 16 px it falls back to the page plus one bold box.

C

Forward mark

Just the deferred glyph », set like a monospace character over a cursor tick. It is the verb at the centre of the app: carry this to tomorrow. The most confident and the most scalable mark — and the most abstract, since » alone leans on the viewer knowing the app.

Follows the color setting. Grayscale mode → ink chevrons. Color mode → accent blue. Swapping the color mark to amber #e5a50a would be the semantically exact choice, since » is the deferred color — shown small under the color pair.

Shipping it

OS icon
Static — icon.ico and the PNGs are baked at build time and can’t follow a runtime setting. Ship one variant; the color version reads better in a taskbar. Generate the set from a single 1024 px master: npx tauri icon icon-master.png rewrites src-tauri/icons/{32x32,128x128,128x128@2x}.png and icon.ico.
In-app icon
An inline SVG in the title bar / About modal can follow color_mode — give its mark fill: currentColor or the --glyph-* custom properties and it themes with everything else, no rebuild.
Both themes
The neutral tile is --tab-bg (#252526 dark, #f3f3f3 light) with a --border hairline, so the icon sits correctly on a dark or light OS shell without a second asset.

Recommendation

Ship A as the OS icon — it is the only mark that names both “notes” and “time” in one glance and holds up at 16 px.

Use B for the in-app icon, where size isn’t a constraint and its grayscale/color split becomes a tiny live demo of the setting itself.
