# Android overrides

`src-tauri/gen/android/` is generated by `tauri android init` and gitignored,
so native tweaks made there are lost if it's regenerated. Files here are the
tracked copies — after (re)running `npx tauri android init`, copy them back:

- `MainActivity.kt` -> `gen/android/app/src/main/java/com/chrononote/app/MainActivity.kt`
  (pads the WebView by the real system-bar/cutout insets so the app's top bar
  isn't drawn under the Android status bar — `env(safe-area-inset-*)` reports 0
  in this WebView).
