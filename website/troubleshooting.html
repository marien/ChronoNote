Troubleshooting

Here are solutions for common setup issues, conflicts, and shortcut problems in ChronoNote.

The installer or an update is blocked

The desktop app runs on Windows 10 and 11. The installer is not signed with a paid code-signing certificate.

When Windows SmartScreen shows "Windows protected your PC", click More info, then click Run anyway.

Smart App Control on Windows 11 blocks unsigned applications completely. ChronoNote cannot run while Smart App Control is turned on. Use the web app at app.chrononote.mariendegelder.nl instead.

"A note changed on disk" and the conflicts folder

This message appears when a note file was edited outside ChronoNote while the app had unsaved edits for the same note.

ChronoNote saves a copy in .chrononote-conflicts\ inside your notes folder so you never lose typing. Open that folder to see the previous text and copy over any lines you need.

"Settings were set aside" (.corrupt-* files)

If ChronoNote cannot read a damaged settings or session file, it renames the file to <name>.corrupt-<number> and starts with default settings.

The app keeps the old file for you in the same folder. Open the corrupt file in a text editor to recover your old settings or tab history.

A global shortcut does nothing

The global shortcut Ctrl+Alt+J opens Peek for your current meeting or call from any application.

If pressing Ctrl+Alt+J does nothing, another running program holds that shortcut. Change the shortcut in Settings → Appearance → Peek.

The web app lost its notes

The web app stores notes in your browser's IndexedDB storage on that device. Clearing site data or cookies in your browser deletes those local notes.

If you connected OneDrive sync, your notes remain safe in your OneDrive account. Open Settings → Notes & Sync, sign in to Microsoft, and pick your notes folder to restore them.

How to report a problem

If you find a bug, open an issue using the GitHub issue form.

Include your ChronoNote version from Settings → About, your Windows version, your display scaling, and steps to reproduce the problem.
