Troubleshooting

Something not working?

Find what you see below, then follow the steps. Nothing here deletes your notes. If your problem is not listed, report it.

On this page
  1. The installer is blocked
  2. "A note changed on disk"
  3. "Settings were set aside"

Windows blocks the installer or an update

The desktop app runs on Windows 10 and 11. Its installer is not signed with a paid code-signing certificate, so Windows warns about an unknown publisher.

What to do
  1. When SmartScreen shows "Windows protected your PC", click More info, then Run anyway.
  2. Smart App Control on Windows 11 blocks unsigned apps completely, and ChronoNote cannot run while it is on. Use the web app instead.

"A note changed on disk"

The note's file was changed outside ChronoNote (by another program, or by OneDrive syncing an edit from another device) while the app had unsaved edits to the same note.

What to do
  1. Nothing is lost: ChronoNote keeps a copy in .chrononote-conflicts\ inside your notes folder.
  2. Open that folder, look at the other text, and copy over any lines you need.

"Settings were set aside" (.corrupt- files)

ChronoNote could not read a damaged settings or session file. It renamed the file to <name>.corrupt-<number> and started with default settings.

What to do
  1. The old file is kept in the same folder (where that is).
  2. Open it in a text editor to recover old settings or tab history, then set them again in the app.

A global shortcut does nothing

Ctrl+Alt+J opens Peek on the current meeting or call from any app. When pressing it does nothing, another running program holds that shortcut.

What to do
  1. Choose another shortcut in Settings → Appearance → Peek.
  2. A locked computer delivers no global shortcuts; unlock it first.

The web app lost its notes

The web app keeps notes in the browser's storage on that device. Clearing site data or cookies for the site deletes them there.

What to do
  1. If you connected OneDrive, your notes are still in your OneDrive folder: open Settings → Notes & Sync, sign in to Microsoft and pick the folder again.
  2. If you exported a backup, drop the file onto the web app's window to bring the notes back.

Reporting a problem

Open an issue with the GitHub issue form. Please include:

  1. your ChronoNote version (Settings → About),
  2. your Windows version and display scaling, or your browser and phone,
  3. the steps that lead to the problem.
