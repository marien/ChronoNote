Why ChronoNote

Built for the way meetings and days actually work

A small, deliberate set of tokens replace themselves with glyphs as you type — the file on disk stays plain text the whole time.

Actions that carry forward

Type #  and it becomes a checkbox. Tabs can't be closed silently while one's still open — a task never quietly disappears at the end of the day.

Section history

Name a section "Daily Standup" or "1:1 — Priya" and ChronoNote aggregates every past occurrence — see what you agreed to last time, instantly.

Cross-tab search

Search every open tab or your entire notes folder at once, with results rendered the same glyph-aware way as the editor itself.

Keyboard-first

A command palette (Ctrl+K), a full shortcut set, and an anchored date picker — the mouse is optional for almost everything.

Paste an agenda in

Copy lines from an email or calendar invite and import them as section headers in one step — additive only, nothing else is touched.

Just plain text, always

One .txt file per day, on your own disk. Open it in Notepad, grep it, sync it however you already sync files — no export step, ever.

The token vocabulary

A handful of tokens, replaced live as you type

The file on disk always stays exactly what you typed — this is a display layer, not a hidden format.

# ☐︎ Open action
v ☑︎ Done
> » Deferred / forwarded
x ☒︎ Won't do
=> ➔︎ Follow-up / delegated to @name
! bold text Emphasis — worth remembering
