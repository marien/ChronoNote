Why ChronoNote

Built for the way meetings and days actually work

A small, deliberate set of tokens replace themselves with glyphs as you type — the file on disk stays plain text the whole time.

Actions that carry forward

Type #  and it becomes a checkbox. Tabs can't be closed silently while one's still open — a task never quietly disappears at the end of the day.

Section history

Name a section "Daily Standup" or "1:1 — Priya" and ChronoNote aggregates every past occurrence — see what you agreed to last time, instantly.

Cross-tab search

Search every open tab or your entire notes folder at once, with results rendered the same glyph-aware way as the editor itself.

Keyboard-first

A command palette (Ctrl+K), a full shortcut set, and an anchored date picker — the mouse is optional for almost everything.

Calendar-aware sections

An opt-in sync turns today's meetings into sections automatically, matched by title against what's already there — anything no longer on the agenda is reviewed, never silently dropped.

Just plain text, always

One .txt file per day, on your own disk. Open it in Notepad, grep it, sync it however you already sync files — no export step, ever.

Lists that keep going

Bullets and numbered lists — 1., 2), even sub-lists like 1.1.. Enter carries the numbering on, an empty item ends the list, Tab nests it. Still plain text.

Write without distraction

Shift+F11 hides every bar for Zen mode. Set your own font size and line spacing, and switch on pure black for OLED screens.

In your browser, too

The web app has the same editor and syncs through OneDrive. Drop a backup or a day's .txt file onto the window to bring it in — nothing is overwritten without asking.

The token vocabulary

A handful of tokens, replaced live as you type

The file on disk always stays exactly what you typed — this is a display layer, not a hidden format.

# ☐︎ Open action
v ☑︎ Done
> » Deferred / forwarded
x ☒︎ Won't do
=> ➔︎ Follow-up / delegated to @name
! bold text Emphasis — worth remembering

On your phone

The same notes on Android

ChronoNote also runs on Android, with a touch-friendly editor and OneDrive sync — the same plain .txt files as on your PC.

Syncs through OneDrive

Pick a OneDrive folder and your daily notes are on your phone and your PC. It syncs when you open the app, after you save, and on demand.

No conflict files

Edited the same note on both? The changes are merged line by line. If you changed the same spot, ChronoNote holds the note and asks which version to keep — inside the app, never as a stray copy.

Install it directly

There's no store listing yet. Download the APK from the Releases page (64-bit ARM phones, Android 7 or newer) and install it — the guide has the steps.
