Your files

Your notes are files you own.

Every day is one plain .txt file in a folder you choose. Open it in any editor, back it up with any tool, sync it with any service. This page shows where everything is, and how to back it up, move it or remove it.

The notes folder

You pick the folder in Settings → Notes & Sync; the default is Documents\Notes. Each day is a file named after its date. The app also keeps a few hidden files and folders there, so they travel with your notes.

Documents\Notes\
  2026-10-27.txt
  2026-10-28.txt
  2026-10-29.txt                 one file per day
  .chrononote-session.json       open tabs and window session
  .chrononote-versions\          earlier versions, 30 days, at most 20 per note
  .chrononote-trash\             notes deleted in the last 30 days
  .chrononote-conflicts\         copies kept when a note changed on disk and in the app at once
  .agenda.json                   optional: your calendar export, for calendar sync

A file named <name>.corrupt-<number> appears only when a settings or session file could not be read and was set aside so the app could start. What to do with it.

Earlier versions and recently deleted notes can be restored from inside the app: getting text back.

Settings and logs

The desktop app keeps its own data in the standard Windows folders, apart from your notes.

WhatWhere
Settings%APPDATA%\com.chrononote.app\config.json
Unsaved scratchpads%APPDATA%\com.chrononote.app\.scratchpads-drafts.json
Logs (today only update.log)%LOCALAPPDATA%\com.chrononote.app\logs\
The app itself (installed per user)%LOCALAPPDATA%\ChronoNote

Backing up

Copy the notes folder. That is the whole backup: any backup tool, an external drive, OneDrive, Dropbox or git works, with no export step. Settings are optional to keep; ChronoNote starts fine without them.

Moving to a new PC

  1. Install ChronoNote on the new computer.
  2. Copy the notes folder to it (or let OneDrive sync it there).
  3. In ChronoNote, open Settings → Notes & Sync and choose that folder.

Uninstalling

Uninstalling removes the app from %LOCALAPPDATA%\ChronoNote. It does not delete your notes folder, your settings in %APPDATA% or your logs in %LOCALAPPDATA%, so a reinstall picks up where you left off. To remove everything, see how to remove everything.

The web app

The web app at app.chrononote.mariendegelder.nl keeps notes in your browser's storage (IndexedDB) on that device. They are the same plain-text notes; export a backup any time from the menu.

Connect OneDrive (Settings → Notes & Sync) to sync them with a folder in your Microsoft account, for example the same folder your PC uses. Clearing the browser's site data removes the notes on that device; synced notes stay in OneDrive.
